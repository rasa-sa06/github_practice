# 受注管理システム（admin）

提案書の②③④にあたる部分です。
全体像は [`../docs/project-map.md`](../docs/project-map.md)、
画面の仕様は [`../docs/admin-system-brief.md`](../docs/admin-system-brief.md)、
技術選定の理由は [`../docs/tech-stack-proposal.md`](../docs/tech-stack-proposal.md) にあります。

## 動かす

```
cd admin
npm install
npm run dev        # http://localhost:3000
```

準備はこれだけです。データベースのインストールもアカウント登録も要りません。
初回の起動時にテーブルを作り、デモと同じ架空の見本データを入れます。

| コマンド | |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm test` | ドメインのテスト（DBを使いません） |
| `npm run typecheck` | 型の確認 |
| `npm run db:reset` | 開発用のDBを消す。次の起動で見本データが入り直します |
| `npm run db:migrate` | 本番（`DATABASE_URL` あり）のテーブル更新 |

開発用のDBは PGlite（アプリに同梱の PostgreSQL）で、`admin/.data/` に入ります。
**1つのプロセスからしか書けません。** 開発サーバーを止めずに別のコマンドで
同じDBを開くと、お互いの書き込みが見えません。入れ直すときは、サーバーを止めてから
`npm run db:reset` してください。

本番は `DATABASE_URL` を見て Neon につなぎます。どちらも PostgreSQL なので、
スキーマも書くコードも同じです。

## いまできていること

| | |
|---|---|
| ✅ | ①きょう（まずはこれから／そのあとで／きょうのクエスト） |
| ✅ | ②注文の一覧（段階順に並ぶ・色は3色） |
| ✅ | 注文の中身（いまここ・一手ボタン・お聞きしていること・LINEをひらく） |
| ✅ | 「1個できた」で進む。最後の1個で自動的に「完成」に入る |
| ✅ | 押し間違いを10分だけ戻せる |
| ✅ | ④きろく（数字4つ・バッジ・今週） |
| ❌ | ログイン — **これが入るまで本番では動きません**（`src/lib/guard.ts` が止めます） |
| ❌ | ③文章をつくる — Claude API の鍵が要ります |
| ❌ | LINE Messaging API — 依頼者のアカウント設定が要ります |

残っている3つは、どれも**依頼者のアカウントか鍵が要る**ものです。
画面の中身が決まらないから止まっているのではありません。

## 始めたばかりの状態を見る

```
npm run db:reset
PUTIERU_SEED=off npm run dev
```

注文が1件も無い状態で起動します。**始めたころは、この画面をいちばん多く開きます。**
デモには無い画面なので、変更するときは必ずここも見てください。

## 組み立て

```
src/
  domain/      画面にもDBにも依存しない、注文の決まりごと
    stages.ts    6段階・3色・その段階での「次の一手」
    orders.ts    記録から「いまの状態」を計算する
  db/          スキーマと問い合わせ
  app/         画面（Next.js App Router）
  lib/guard.ts ログインが入るまで本番で動かないための止め金
```

**注文には「ステータス」も「進捗」も持たせていません。**
持っているのは「やったこと」を1行ずつ足しただけの記録（`order_events`）で、
段階も個数も並び順も、そこから数え直して出しています。

理由は [`src/domain/orders.ts`](src/domain/orders.ts) の先頭に書いています。
短く言うと、④きろく（今月つくった数・続いている日数・バッジ）を
あとから何も足さずに出せるようにするためと、
**ゲーム要素のための入力を構造上できなくする**ためです。

`src/domain/` は DB も画面も見ないので、テストが速く、設計ルールを直接テストできます。
「色は3色しか使わない」「どの段階にも一手がちょうど1つある」も
[テスト](src/domain/orders.test.ts)で固定しています。
