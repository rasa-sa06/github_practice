## 1. 納期について（優先度：高）

FAQ に載せたい項目ですが、実績が分からないため未掲載です。

- お問い合わせから納品まで、だいたい何日くらいかかりますか？
- 繁忙期（入学式前など）は変わりますか？
- 「〇日までに欲しい」というご相談には応じられますか？

> 掲載イメージ:
> 「お問い合わせから発送まで、おおよそ〇〇日ほどいただいています。
> 入学式シーズンなど混み合う時期は前後しますので、お急ぎの場合はご相談ください。」

## 2. 最小注文数（優先度：高）

- 1個から注文できますか？
- 団体オーダーの場合、何個からですか？

## 3. お支払い方法（優先度：高）

- どの支払い方法に対応していますか？（銀行振込 / PayPay / クレジットカード など）
- お支払いのタイミングは？（制作前 / 完成後 / 発送前）

## 4. 送料（優先度：中）

- 送料はいくらですか？ 全国一律ですか？
- 何円以上で送料無料などはありますか？
- 手渡し（マルシェでの受け取り）は可能ですか？

## 5. 返品・交換（優先度：中）

- オーダー品の返品・交換は受け付けていますか？
- イメージと違った場合の対応は？

## 6. 素材・お手入れ（優先度：低）

- 洗えますか？ お手入れ方法は？
- 金属アレルギーなどへの配慮が必要な素材を使っていますか？

## 7. 対応エリア（優先度：低）

- 発送は全国対応ですか？
- 海外発送は？

## 解決済み

### お問い合わせフォーム → LINE公式アカウントに一本化（対応済み）

以前の `contact.html` のフォームは、押しても**実際には送信されません**でした
（静的サイトのため、送信を受け取る仕組みがなかったためです）。
LINE公式アカウント <https://lin.ee/n2cV2Gv> をご共有いただいたので、
提案書の方向性どおり、窓口をLINEに一本化しました。

- `contact.html` — フォームを廃止し、「LINEで相談する」ボタンに置き換え
  （InstagramのDMも代替の窓口として併記）
- `index.html` / `custom.html` / `faq.html` の相談ボタン — LINEへのリンクに変更

窓口が1つになったので、問い合わせの取りこぼしと管理の分散がなくなります。
フォーム廃止にともない、サイトから JavaScript が完全になくなりました。
