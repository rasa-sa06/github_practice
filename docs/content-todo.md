- オーダー品の返品・交換は受け付けていますか？
- イメージと違った場合の対応は？

方針が決まり次第、FAQ に1問追加します。追記位置は `faq.html` の

オーダーメイドは受注生産なので、「原則お受けできません」という方針でも
まったく問題ありません。**書いていないことが一番トラブルになります**ので、
どちらに決まっても載せることをおすすめします。

### 特定商取引法に基づく表記（下書きあり）

（`noindex`／sitemap 未掲載／どこからもリンクなし）。

**依頼者に聞くこと**

| 項目 | 補足 |

| 運営統括責任者 | 個人であれば上と同じ氏名で構いません |
| 所在地 | 自宅住所を出したくない場合は下記参照 |

**住所・電話番号について。** 個人でハンドメイドを販売する場合、ここが一番の
ハードルになります。自宅住所と個人の電話番号を載せることに抵抗があるのは
自然なことなので、バーチャルオフィスの利用など、ほかの作家さんがどうしているかを
含めて一度調べることをおすすめします。**こちらで法的な判断はできない**ので、
不安があれば専門家にご相談ください。

そもそも該当するかどうかも含めて、最終的には依頼者の判断になります。
ただ、送料・支払い方法・納期を掲げて注文を受ける形になっている以上、
**用意しておく方が安全**だと考えています。

### お問い合わせフォーム → LINE公式アカウントに一本化

以前の `contact.html` のフォームは、押しても**実際には送信されません**でした
（静的サイトのため、送信を受け取る仕組みがなかったためです）。
LINE公式アカウント <https://lin.ee/n2cV2Gv> をご共有いただいたので、
提案書の方向性どおり、窓口をLINEに一本化しました。

- `contact.html` — フォームを廃止し、「LINEで相談する」ボタンに置き換え
  （InstagramのDMも代替の窓口として併記）
- `index.html` / `custom.html` / `faq.html` の相談ボタン — LINEへのリンクに変更

窓口が1つになったので、問い合わせの取りこぼしと管理の分散がなくなります。
フォーム廃止にともない、サイトから JavaScript が完全になくなりました。
