## 確認しておきたい2点（急ぎではありません）

### 1.「1度限り」の解釈

返品・交換について「1度限り」とご回答をいただきましたが、
**1回のご注文につき1度**と解釈して掲載しています。
「お一人様につき生涯1度」という意図でしたら、文言を直します。

### 2. 返品・交換の申し出期限

「商品到着後〇日以内にご連絡ください」という期限が決まっていません。
現在は期限を書かず「お手元に届きましたら、まずはご連絡ください」としています。

期限がないと、数か月後の申し出も断りにくくなります。
**到着後7日以内**あたりが一般的です。決めていただければ追記します。

## 運用上の申し送り

### 所在地・電話番号の開示請求には必ず答えてください

`tokushoho.html` では、所在地と電話番号を「ご請求いただいた場合、遅滞なく開示いたします」
として非掲載にしています。特定商取引法がこの省略を認める条件は、
**実際に請求へ遅滞なく応じること**です。

LINE や Instagram に「住所と電話番号を教えてください」と連絡が来たら、
その場でお答えする必要があります。書いてあるだけでは条件を満たしません。

### クレジットカード決済を導入する場合は再検討が必要

決済代行会社の加盟店審査は特商法より厳しく、住所を番地まで、電話番号も必須と
される場合があります。非開示のままだと一部のカードブランドで審査が通らない
可能性があるため、その段階でバーチャルオフィスの利用などを検討することになります。

参考にした情報:
- <https://stores.fun/magazine/articles/netshop-tokushoho-guide>
- <https://lala-clip.com/law-page-privacy/>
- <https://support.cardservice.co.jp/hc/ja/articles/20542579141785>

**法的な判断はこちらではできません。** 上記は一般に公開されている情報を
まとめたものです。不安があれば専門家にご確認ください。

### お問い合わせフォーム → LINE公式アカウントに一本化

以前の `contact.html` のフォームは、押しても**実際には送信されません**でした
（静的サイトのため、送信を受け取る仕組みがなかったためです）。
LINE公式アカウント <https://lin.ee/n2cV2Gv> をご共有いただいたので、
提案書の方向性どおり、窓口をLINEに一本化しました。

- `contact.html` — フォームを廃止し、「LINEで相談する」ボタンに置き換え
  （InstagramのDMも代替の窓口として併記）
- `index.html` / `custom.html` / `faq.html` の相談ボタン — LINEへのリンクに変更

窓口が1つになったので、問い合わせの取りこぼしと管理の分散がなくなります。
フォーム廃止にともない、サイトから JavaScript が完全になくなりました。
