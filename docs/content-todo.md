#### 所在地・電話番号は非公開にしています

特定商取引法では、**請求があった場合に遅滞なく開示する旨を広告に表示し、
実際に開示できる措置を講じていれば**、住所・電話番号の表示を省略できます。
消費者庁も、個人でショップを運営する人が個人情報を非公開にしてよいという
見解を示しています。決済手段とは無関係の条件です。

ページには次の一文を入れてあります。

> 所在地・電話番号は上記のとおり掲載しておりませんが、ご請求いただいた場合は
> 遅滞なく開示いたします。LINE公式アカウント、または Instagram のDMより
> お申し付けください。

**⚠ 書いただけでは足りません。** 請求が来たときに実際に遅滞なく答える運用が
条件です。LINE か Instagram に「住所と電話番号を教えてください」と来たら、
その場で返す — これを依頼者に伝えておいてください。

**⚠ 将来クレジットカード決済を導入する場合は要再検討。** 決済代行会社の
加盟店審査は特商法より厳しく、住所を番地まで、電話番号も必須とされることが
あり、非開示だと一部のカードブランドで審査が通らない可能性があります。
その段階でバーチャルオフィスの利用などを検討することになります。

参考にした情報:
- <https://stores.fun/magazine/articles/netshop-tokushoho-guide>
- <https://lala-clip.com/law-page-privacy/>
- <https://support.cardservice.co.jp/hc/ja/articles/20542579141785>

**法的な判断はこちらではできません。** 上記は一般に公開されている情報を
まとめたものです。不安があれば専門家にご確認ください。

### お問い合わせフォーム → LINE公式アカウントに一本化

提案書の方向性どおり、窓口をLINEに一本化しました。

- `contact.html` — フォームを廃止し、「LINEで相談する」ボタンに置き換え
  （InstagramのDMも代替の窓口として併記）
- `index.html` / `custom.html` / `faq.html` の相談ボタン — LINEへのリンクに変更

窓口が1つになったので、問い合わせの取りこぼしと管理の分散がなくなります。
フォーム廃止にともない、サイトから JavaScript が完全になくなりました。
