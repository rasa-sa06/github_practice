# わたしの荷物、あなたの荷物 — 課題の分離トレーニング

人の不機嫌を「自分のせいだ」と背負ってしまう人のための、アドラー心理学の
「課題の分離」を練習するアプリです。
アダルトチルドレンや HSP の傾向があって、

- 余裕がなくなって、子どもへの接し方がキツくなってしまう
- 家族や職場の人の不機嫌にビクビクしてしまう

という子育て中の人を、最初の対象にしています。

> ぷてぃえーるのサイトとは別の、個人の練習用アプリです。
> フォルダを分けているので、サイトのページ・sitemap とは混ざりません。

## 開き方

ビルドは不要です。`index.html` をブラウザで開けば動きます。
公開サイトに載ると `/kadai-bunri/` で開けます（`noindex` なので検索結果には出ません）。

## できること

| 画面 | 内容 |
|---|---|
| いまのモヤモヤを整理する | 6ステップのワーク（下記） |
| 練習問題 | よくある場面で「誰の荷物？」を3択で答え、理由の解説を読む |
| 課題の分離ってなに？ | 考え方・なぜ難しいのか・よくある誤解 |
| これまでの記録 | ワークの記録（不安度の変化、返した荷物、やってみること） |
| しんどい時 | 呼吸ガイド、5-4-3-2-1 グラウンディング、相談窓口 |

### 整理ワークの流れ

1. **いまの不安度**（0〜10）— 8以上なら先に呼吸を勧める
2. **起きたこと** — 誰との間か＋「事実だけ」を書く（解釈と分ける）
3. **浮かんだ考え** — 「私が何かしたのかも」などを選ぶ
4. **仕分け** — 項目ごとに「自分 / 相手 / 共同」に分ける。
   見分ける質問は「その結果を最終的に引き受けるのは誰？」
5. **手放す** — 相手の荷物に「〇〇の課題。私が背負わなくていい」と言葉を添え、
   自分の荷物の中から「いまできる小さなこと」を1つ決める
6. **ふりかえり** — もう一度不安度をはかり、記録する

## 設計で気をつけたこと

- **「不正解」と言わない。** 仕分けが目安と違っても「こんな見方もあります」と添えるだけ。
  自分を責めやすい人が、さらに責める道具にならないようにしています。
- **課題の分離＝突き放し、ではないと明記。** 子どもの安全は親が守る、
  暴言・暴力を「相手の課題だから」と我慢しない、を「学ぶ」画面に書いています。
- **記録は端末の外に出さない。** `localStorage`（ブラウザの中の保存場所）だけを使い、
  サーバーへは送りません。そのかわり、別の端末とは共有されません。
- **医療の代わりではない。** 相談窓口をいつでも開ける位置（ヘッダーの「しんどい時」）に置いています。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 全画面の HTML（表示する画面だけ JS で切り替える） |
| `style.css` | 見た目。色は先頭の変数にまとめ、ダークモードにも対応 |
| `app.js` | 場面・練習問題のデータと、画面の動き |

場面の候補や練習問題を増やしたいときは、`app.js` の `SCENES` と `QUIZ` に足してください。
